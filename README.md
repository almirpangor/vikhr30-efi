# Вихрь-30 EFI

Блок управления впрыском и зажиганием для лодочного мотора «Вихрь-30» на STM32F103C6T6 (Blue Pill):
программа настройки, прошивка, схема и печатная плата.

| Папка | Что внутри |
|---|---|
| `app/` | Программа настройки 2.0 (TypeScript, React, свой WebGL-движок). `app/desktop/` — оболочка настольного приложения (Electron). Сборка: `node build.mjs`, тесты ядра: `npm test`. |
| `firmware/` | Прошивка v0.9 (исправленная) и v0.8 (для отката), симулятор и тесты на хосте, готовые HEX/BIN в `firmware/release/`. Читать `firmware/README_RU.md`. |
| `pcb/` | Печатная плата rev A: генератор, Gerber и сверловка в `pcb/out/`, файл KiCad, сборочные рисунки, перечень. Читать `pcb/out/README_RU.md`. |
| `release/` | Собранная программа одним HTML-файлом (Chrome/Edge). Установщик для Windows — в разделе Releases. |

## Состояние

Проверено без железа: 24 автотеста ядра программы, 48 проверок прошивки на симуляторе, соответствие Gerber схеме по всем 63 цепям.

**Не проверено на железе:** прошивка v0.9 на настоящем контроллере, программа с настоящим COM-портом,
установщик на Windows, плата (не изготавливалась, файл KiCad в KiCad не открывался), схема из новых деталей.
Перед заказом платы — список «Сверить перед заказом» в `pcb/out/README_RU.md`.

Первые включения — на стенде, с предохранителем и ограничением тока, без топлива. Цепи катушек — до 400 В.
